## Project Overview
### What the robot is

-A small DIY quadruped robot dog controlled by an ESP32.

-It uses servo motors to control its legs, neck, and tail.

-An OLED display provides animated eyes and facial expressions.

### Why we created it

-To learn and demonstrate robotics, electronics, and programming.

-To create a robot that is interactive, friendly, and expandable with AI.

### Main Objective

To design and build a programmable robot dog that can move, interact with humans, and demonstrate smart robotic features.

## ✨ Features

-🦵 4-Leg Walking — Servo-controlled legs for walking and standing.

-🐕 Neck Movement — Head can move left and right.

-🦴 Tail Movement — Tail moves to make the robot more realistic.

-👀 Animated Eyes — OLED display shows blinking and different eye expressions.

-😊 Emotion Display — Happy, sad, angry, sleepy, and surprised expressions.

-🧠 ESP32 Control — ESP32 acts as the main controller.

-🎮 Programmable Movements — Different movements can be programmed using Arduino IDE.

## How It Works

Input → ESP32 → Servo/display → Robot action

## Movement System

🦵 Leg Movement

Four legs are controlled by servo motors.

Coordinated movements allow sitting, and standing.

Servo angles are programmed for stable movement.

🐕 Neck Movement

A servo controls the head/neck.

The head can move left and right.

This allows the robot to look around.

🦴 Tail Movement

A servo controls the tail.

The tail can move left and right.

Different movements can represent emotions.
